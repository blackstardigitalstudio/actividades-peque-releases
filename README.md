# Actividades con tu peque — Releases 🦉

Repository pubblico che ospita **solo** gli APK e il file `latest.json` per
l'**aggiornamento automatico** dell'app. Il codice sorgente è in un repo privato.

- L'app legge `latest.json` e, se c'è una versione più recente, mostra il pulsante **Aggiorna**.
- Scarica l'ultimo APK dalla sezione **Releases**.
